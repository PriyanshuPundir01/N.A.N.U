# NANU — Your AI Assistant ⚡

A fast, modern, and intelligent AI chat application with real-time streaming, speech-to-text dictation, multimodal file/image attachments, deep thinking mode, and easy switching between 100% free AI models.

## ✨ Features

- **⚡ Fast Streaming**: Real-time AI response streaming with markdown and code syntax highlighting.
- **🔄 Quick Model Switcher**: Easily switch free AI models right from the search bar (Gemini Flash Lite, Gemini 3.8 Flash, Qwen 2.5 27B, and local offline assistant).
- **🎙️ Voice Dictation**: Speech-to-text voice input directly into the search bar.
- **📁 File & Image Attachments**: Attach documents, code files, and images.
- **💡 Deep Thinking Mode**: Toggle step-by-step reasoning for complex problems.
- **🔒 Authentication System**: User registration, login, and profile management.
- **🌙 Sleek Dark/Light Mode**: Premium glassmorphism UI with smooth animations.

## 🚀 Getting Started

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)

### 2. Installation
```bash
# 1. Clone the repository
git clone https://github.com/PriyanshuPundir01/N.A.N.U.git
cd N.A.N.U

# 2. Install dependencies
npm install

# 3. Configure environment variables
# Copy the example file and add your free Google AI Studio key:
cp .env.example .env
```

### 3. Run the App
```bash
npm start
```
Open your browser and navigate to `http://localhost:3000`.

## 🛡️ Privacy & Security
- API keys and user credentials are kept in `.env` and `users.json`, which are excluded from Git via `.gitignore`.
